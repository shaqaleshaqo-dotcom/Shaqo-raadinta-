# SHAAQO HEL — Android starter

Mashruuc bilow ah oo Android ah, Af-Soomaali ku qoran.

## Sida loo furo
1. Kombiyuutar ku rakib Android Studio.
2. Fur Android Studio, dooro **Open**.
3. Dooro galka `SHAAQO_HEL_Android_Starter`.
4. Sug Gradle Sync, kadib ku tijaabi emulator ama telefoon Android ah.

## Waxa ku jira
- Bogga hore iyo liiska shaqooyinka tusaalaha ah.
- Raadinta shaqooyinka.
- Foom shaqo lagu soo gudbiyo.
- Bog maamule oo shaqo lagu oggolaado ama lagu diido.

## Muhiim
Kani waa prototype bilow ah. Xogtu waxay ku jirtaa xusuusta app-ka oo keliya; way lumi kartaa marka app-ka dib loo bilaabo. Ma laha weli server, diiwaangelin dhab ah, kayd xogeed online ah, xaqiijin shaqo-bixiye, ogeysiisyo, ama ilaalin maamul oo server-ku xaqiijiyo. Kahor daabacaadda Google Play waa in lagu daraa backend ammaan ah iyo gelitaan maamule oo gaar ah.
